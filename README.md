# CODSOFT Data Science Internship Tasks

## Project Overview
This repository contains the projects completed as part of my **CODSOFT Data Science Internship**. The projects focus on data cleaning, exploratory data analysis, and data visualization using Python.

## Tasks Completed

### Task 1: Data Cleaning and Preprocessing
**Objective:** Clean and prepare customer churn data for analysis.

**Activities:**
- Inspected the dataset structure and data types.
- Checked for missing values and duplicate records.
- Performed data cleaning and preprocessing using Pandas.
- Exported the processed dataset as a CSV file.

**Files:**
- `task1_data_cleaning.ipynb`
- `cleaned_customer_data.csv`
- `exported_churn_data.csv`

### Task 2: Exploratory Data Analysis (EDA)
**Objective:** Explore customer churn data to identify patterns, trends, and relationships.

**Activities:**
- Analyzed the dataset using descriptive statistics.
- Examined customer churn and contract types.
- Explored monthly charges, churn scores, and cancellation reasons.
- Created visualizations to understand customer behavior.

**Files:**
- `task2_exploratory_data_analysis.ipynb`
- `README.md`
- `graphs/`

### Task 3: Data Visualization
**Objective:** Present customer churn insights through meaningful visualizations.

**Activities:**
- Created bar charts, histograms, pie charts, line charts, and scatter plots.
- Visualized churn distribution and contract types.
- Explored monthly charges and churn scores.
- Saved charts as PNG images for easy viewing.

**Files:**
- `task3_visualization.ipynb`
- `README.md`
- `graphs/`
