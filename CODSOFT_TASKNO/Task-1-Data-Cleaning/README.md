# Task 1: Data Cleaning and Preprocessing

## Project Overview
This project focuses on cleaning and preprocessing customer churn data using Python and Pandas.

## Objectives
- Import and inspect the dataset.
- Identify missing values and duplicate records.
- Check data types and inconsistent entries.
- Clean and prepare the dataset for further analysis.
- Export the cleaned dataset as a CSV file.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Project Files
- `task1_data_cleaning.ipynb` — Notebook containing the data-cleaning process.
- `cleaned_customer_data.csv` — Cleaned dataset.
- `exported_churn_data.csv` — Exported dataset used in the project.

## Conclusion
The project demonstrates basic data-cleaning and preprocessing techniques that help prepare customer data for exploratory data analysis and visualization.

## How to Run
1. Install Python and Jupyter Notebook.
2. Install dependencies using `pip install pandas numpy`.
3. Open `task1_data_cleaning.ipynb`.
4. Run the notebook cells in order.
