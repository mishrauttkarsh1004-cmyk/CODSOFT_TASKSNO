# Task 2: Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on customer churn data. The goal is to understand customer behavior, explore patterns in the dataset, and identify factors that may be associated with customer churn.

## Objectives
- Understand the structure of the dataset.
- Analyze customer churn distribution.
- Explore the relationship between contract type and churn.
- Analyze customer cancellation reasons.
- Examine monthly charges and churn score distributions.
- Identify useful patterns through data visualization.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
1. Dataset overview and statistical summary.
2. Missing-value and duplicate checks.
3. Customer churn distribution visualization.
4. Contract type vs. churn analysis.
5. Cancellation reason analysis.
6. Monthly charges distribution.
7. Churn score distribution.

## Project Files
- `task2_exploratory_data_analysis.ipynb` — EDA notebook.
- `exported_churn_data.csv` — cleaned dataset used for analysis.
- `graphs/` — saved visualizations.

## Conclusion
This analysis helps explore customer churn patterns and understand customer characteristics through statistics and visualizations. The findings can support further investigation into customer retention strategies.

## How to Run
1. Install Python and Jupyter Notebook.
2. Install the required libraries using `pip install pandas numpy matplotlib seaborn`.
3. Keep the CSV file in the same folder as the notebook.
4. Open and run `task2_exploratory_data_analysis.ipynb`.
