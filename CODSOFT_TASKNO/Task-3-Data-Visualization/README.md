# CODSOFT Task 3: Data Visualization

## Project Overview
This project visualizes customer churn data using Python libraries. It explores customer behavior, monthly charges, contract types, cancellation reasons, and churn score distribution.

## Objectives
- Visualize customer churn distribution.
- Compare contract types with churn status.
- Analyze monthly charges.
- Identify common cancellation reasons.
- Explore churn score distribution.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Visualizations
1. Customer Churn Analysis
2. Contract Type vs Customer Churn
3. Distribution of Monthly Charges
4. Customer Cancellation Reasons
5. Customer Churn Score Distribution

## Files
- `task3_visualization.ipynb` — Jupyter Notebook containing the analysis.
- `exported_churn_data.csv` — Dataset used for visualization.
- `graphs/` — Saved graph images.

## Conclusion
The visualizations provide an overview of customer churn patterns and related characteristics. These findings can help identify areas for further investigation into customer retention.

## How to Run
1. Install Python and Jupyter Notebook.
2. Install dependencies: `pip install pandas numpy matplotlib seaborn`.
3. Place the CSV file in the same folder as the notebook.
4. Run all cells in `task3_visualization.ipynb`.
